## General guidance

- Always clearly define acronyms, variable names, and other non-standard jargon
- In general, make descriptions and interpretations of results clear, concise, complete, and intuitive, using as little jargon as possible

## Grammar, etc

- Use American, not British, English

## Figures

- Use a minimum font size of 12pt for all text in matplotlib figures (titles, axis labels, tick labels, legends, annotations) whenever the layout allows it — the default sizes are too small to read comfortably.
